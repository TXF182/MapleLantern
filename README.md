## 主要特性（当前 1.5.7）

- **布景九层**：背景 1–4 与前景 1–5 独立开关、层级、图库、预设与地点滤镜；83 张重绘图由独立图库包提供，自动背景默认关闭、仅对显式名单地点生效，接管前会备份并可在关闭时恢复玩家原图。

- **八套主题 + 自动**：默认赛博朋克（深蓝黑底、青蓝主光、洋红副光），可切琥珀 / 青瓷 / 星空 / 雾港 / 旧校舍 / 纸灯 / 绿茵；每套覆盖面板、顶栏、弹层、状态卡与正文，含专属纹理与对比度校正。绿茵为阳光草场浅色档，浮层、卡片与按钮边缘用青绿描边。
- **主题预览卡**：设置页每套主题一张 mini 场景卡，底色、强调光、纹理与正文层级一眼可比；选中卡用主题强调色描边并显示勾选。
- **主题边饰**：正文四周一层随主题换纹样的装饰花边，每套主题一种独立符号语言；可总开关。
- **正文文字色**：设置页给「跟随主题 + 主题预设色点 + 自定义取色」，只作用于故事正文与标题；预设与自定义都按当前主题底色校验 ≥4.5:1，换到不达标的主题会自动回跟随主题。
- **按压反馈**：按钮、页签、控件、图标与开关按下时轻微缩放提亮（不下沉），生成主题色涟漪；系统减少动效或设置关闭动效时不播放。
- **主题环境层**：各主题专属粒子与光层；面板打开时环境层降亮，窄屏自动降载，动效可整体关断。
- **动效**：面板、侧栏光带、页签、表盘等全套动效，三路关断（面板开关、模组开关、系统减少动效）。
- **原生界面卡片化**：顶栏四格、状态大卡、正文选项卡片、侧栏入口与弹层统一卡片语言。
- **星空主题**：固定深空星场铺满整页，星点不随长文滚动拉伸。
| 主题边饰 | 开 / 关 | **开** |
| 正文文字色 | 跟随主题 / 主题预设 / 自定义 | 跟随主题 |
- **左轨可读性**：状态标签下补数值条，0 值也保留轨道。
- **中英文文案**：面板文案与商店工具栏跟随语言；中文环境本地化未翻译的工具栏词条。
- **第三方只读联动**：识别常见美化模组时显示其状态摘要并提供跳转入口，不写第三方状态；美化页保留灯台入口、默认不接管其界面。
- **只读、可降级**：不写存档、不改数值、不接管第三方业务；宿主界面启用时由玩家开关决定是否挂载外观；设置损坏时逐字段回退。

## 安装

1. 打开游戏，按 `Alt+M` 呼出 ModLoader。
2. 「添加旁加载 Mod」选择 `MapleLantern-1.5.8.mod.zip`；已装旧包先停用再导入，同名技术身份只能启用一个版本。
3. 再导入 `MapleLantern-ImagePack-1.5.8.mod.zip` 布景图库；只装本体也能运行布景功能，但没有图可显示。
4. 刷新页面。

> 把 zip 复制进游戏目录不等于安装：模组由浏览器本地数据库加载。
